# Security Policy

## Current support status

NEXAH Experience is a pre-release static website. No production release or
long-term supported version has been declared.

## Reporting a vulnerability

Report suspected security or privacy issues privately to
[`contact@nexah.de`](mailto:contact@nexah.de). Do not include credentials,
private personal data or exploit details in a public issue.

Please include:

- the affected page, file or revision;
- steps to reproduce;
- the observed and expected boundary;
- the likely impact; and
- whether the report concerns the static Experience, generated data or an
  external service.

## Boundary

This repository owns the public presentation layer. Reports concerning NEXAH
Framework or ORION behavior will be routed to their canonical owner. External
services, including hosting, GitHub and Are.na, retain their own security
responsibilities.

No bounty, response-time guarantee or production support commitment is implied
by this pre-release policy.
