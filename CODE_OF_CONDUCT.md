# Code of Conduct

Participation in NEXAH Experience follows the canonical
[NEXAH Code of Conduct](https://github.com/Scarabaeus1031/NEXAH/blob/main/CODE_OF_CONDUCT.md).

That document governs community conduct. This repository's
`CONTRIBUTING.md` separately defines the Experience authority boundary and
verification requirements. Referencing the canonical policy does not duplicate
its authority.
