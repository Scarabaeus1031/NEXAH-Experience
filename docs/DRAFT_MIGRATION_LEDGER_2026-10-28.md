Date: `2026-10-28`

Scope: points 1–6 of the agreed nexah.de integration pass

## Purpose

This ledger prevents the temporary `DRAFT` shelf from becoming a second public
definition of NEXAH. It classifies the material currently gathered in
`A0_HUMAN_BOOK_DRAFT.html` against the existing public houses and source
authorities.

The source file remains an editorial holding object. Classification here does
not activate a Study, publish an instrument, create a Library identity or
authorize removal of the `DRAFT` control from the private A0 Owner frame.

## Public ownership rule

| Public destination | Owns | Does not own |
|---|---|---|
| About NEXAH | purpose, definition, public responsibilities and boundaries | a second archive, scientific status or complete instrument inventory |
| Human View / NEXAHEDRON | bounded Human-facing interaction, reflection and Return | Science authority, Builder authority or automatic state transfer |
| NEXAH Science | bounded questions, methods, evidence, results and open limits | Human meaning or automatic publication |
| Builder / How NEXAH Works | public explanation of source, aperture, difference, boundary and Return | private tools, execution authority or scientific promotion |
| Library | source-bound records of approved published works | automatic publication of every draft, image or instrument |

## Migration decisions

Decision vocabulary:

- `MERGED`: the public idea is already represented in the current nexah.de cut.
- `ROUTE`: nexah.de explains and points to the named owning public house.
- `CATALOG REVIEW`: a source-bound publication identity is required before a Library record can be added.
- `SOURCE ONLY`: retain at the owning source; do not expose the internal page directly.
- `HOLD`: no present public role has been approved.

## Library reconciliation

The current generated Experience catalog was searched for the named Light,
Body/Life and Method/Map draft labels. None of those labels is presently a
source-bound public catalog identity; `One Pulse` appears only as a reader
source chapter label, and `Tessarec` appears in the Rödelheim Observatory copy.
Neither occurrence authorizes a new Library publication record.

For each `CATALOG REVIEW` item, admission requires:

1. one canonical title and owning source;
2. public/release approval and license boundary;
3. source URL or repository record;
4. a stable catalog identity rather than a display label from the draft;
5. an explicit decision whether it is a publication, instrument or Human View scene.

## Completed in this pass

- About uses one maintained public identity source and one set of three views.
- Human View routes to NEXAHEDRON rather than copying the A0 draft runtime.
- How NEXAH Works defines Source, Aperture, Difference, Boundary and Human Return.
- The multi-instrument/no-state-transfer boundary is public and machine-readable.
- The Library states that draft labels and instruments are not publications by default.
- README, `llms.txt`, AI Markdown, ecosystem JSON and JSON Schema derive from the same maintained identity data.
