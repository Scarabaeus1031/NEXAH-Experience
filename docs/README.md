# Experience Documentation

These documents govern the public experience without redefining NEXAH or ORION
architecture.

The adopted
[NEXAH Ecosystem Constitution v1.0](https://github.com/Scarabaeus1031/NEXAH/blob/main/GOVERNANCE/ECOSYSTEM_CONSTITUTION.md)
defines the Experience House and remains the highest governance source. The
documentation order is Constitution → Governance → Architecture → repository
documentation → implementation → derived artifacts. This directory begins at
the Experience repository-documentation level and may specialize presentation,
but it cannot amend a higher level.

The First User Journey in the ORION workshop is preserved as the historical
source for Product Sprint 01. The maintained Experience documents in this
repository are now canonical for presentation, navigation and journey
choreography. They remain consumers of ORION reports and Library records rather
than authorities over them.
